# upcoming-report — справка по приближающимся срокам

## Зачем

`overdue_report.py` показывает то, что **уже** просрочено или горит сегодня.
Этот скилл отвечает на вопрос вперёд: **какие задачи уйдут в просрочку**,
если не закрыть их в срок — за произвольное окно дат.

Выгрузка — два формата одного содержания:
- `.txt` — как `overdue_tasks_*.txt`, готов к копированию в Telegram;
- `.md` — как `СПРАВКА_*.md`: шапка с разбивкой по датам, детализация таблицами
  по проектам, краткая сводка, блок «Обратить внимание».

## Как запускать

```bash
python3 upcoming_report.py                          # сегодня .. +7 дней, txt + md
python3 upcoming_report.py --to 17.08.2026          # сегодня .. конкретная дата
python3 upcoming_report.py --days 4                 # сегодня .. +4 дня
python3 upcoming_report.py --from 18.08.2026 --to 24.08.2026   # произвольное окно
python3 upcoming_report.py --format md              # только markdown (txt | md | both)
python3 upcoming_report.py --include-overdue        # добавить ранее просроченные
python3 upcoming_report.py --stdout                 # в консоль, без записи файлов
python3 upcoming_report.py --outdir /tmp/x          # другой каталог выгрузки
```

Имена файлов формируются по окну: `СПРАВКА_сроки_13-17.08.2026.{txt,md}`
(переопределяется `--output ИМЯ` — без расширения).

## Что делает

1. Читает `data.json` (`--data`, по умолчанию из текущего каталога) — **только читает**,
   пайплайн не запускает и рабочие файлы не трогает.
2. Отбирает задачи: дедлайн в окне `[--from .. --to]` включительно **и** статус
   не входит в `CLOSED_STATUSES`.
3. Группирует по проекту (ответственный, ссылка, приоритетность — из `projects[]`),
   сортирует группы по ближайшему сроку, задачи внутри — по дате.
4. Пишет `.txt` и/или `.md` в `--outdir` и печатает итог в консоль.

## Ограничения и нюансы

- Свежесть справки = свежесть `data.json`. Если выгрузка Redmine новее —
  сначала `./deploy.sh …` (запускает **владелец**, см. правило про песочницу в `CLAUDE.md`),
  затем эта команда. Скрипт сам показывает `updated_at` в шапке и подставляет имя
  выгрузки `issues*.xlsx`, если её mtime совпадает с `updated_at`.
- Считается календарный срок: задача со сроком в субботу отражается как есть,
  в блоке «Обратить внимание» отдельной строкой указан предшествующий рабочий день.
- Ранее просроченные в справку **не входят** (только справочная строка со счётчиком) —
  для них `overdue_report.py`; чтобы свести всё в один документ, есть `--include-overdue`.
- Проект без строки в файле высвобождения не имеет `url` — в справке у такого
  проекта не будет ссылки, задачи при этом со ссылками.
