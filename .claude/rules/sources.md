# Источники данных (Excel, в git не хранятся)

_Вынесено из `CLAUDE.md` 10.09.2026._

## Источники данных (Excel, в git не хранятся)

| Файл | Содержимое |
|------|-----------|
| `issues.xlsx` / `issues (1).xlsx` | Выгрузка из Redmine (трекеры: Паспорт проекта, Мероприятие проекта) |
| `ШТАТКА_ДБ.xlsx` | Штатная численность по кураторам |
| `ПРОЕКТЫ_Данные по высвобождению.xlsx` | Данные по высвобождению (шт.ед., часы) |

> Имена в таблице — канонические (fallback). Фактические файлы лежат в корне с датой в имени
> (`ШТАТКА_ДБ_15.06.2026.xlsx`, `Проекты_Данные по высвобождению_15.06.2026.xlsx`); актуальным
> считается самый свежий — `deploy.sh` определяет его автоматически (см. «Обновление данных»).
> `data.json.bak` — резервная копия `data.json`, которую `process_report.py` создаёт при каждом
> запуске; в git не хранится (`.gitignore`: `.DS_Store`, `data.json.bak`).

## Архив (`archive/`)

Старые датированные файлы вынесены из корня в `archive/` (в корне остаётся рабочий набор
за последнюю неделю):

| Подкаталог | Содержимое |
|-----------|-----------|
| `archive/issues/`   | старые выгрузки Redmine `issues_*.xlsx` |
| `archive/reports/`  | старые `ОТЧЕТ_*.md` (отслеживаются git) |
| `archive/telegram/` | старые `telegram_priority/transform_*.txt` |
| `archive/overdue/`  | старые `overdue_tasks_*.txt` |
| `archive/source/`   | старые штатка/высвобождение и прочие исходные xlsx |

Архивные `*.xlsx`/`*.txt` остаются вне git (глобальные правила `.gitignore`), поэтому ни
`git add .`, ни глобы автоопределения в `deploy.sh` их не цепляют. `ОТЧЕТ_*.md` отслеживаются
git и переносятся через `git mv` (история сохраняется).
