## Отчёт по просроченным задачам (`overdue_report.py`)

Скрипт формирует текстовый отчёт по всем просроченным задачам **и задачам со сроком сегодня** из `data.json`.

### Запуск

```bash
python3 overdue_report.py
python3 overdue_report.py --data data.json
python3 overdue_report.py --output overdue_tasks_28_05_2026.txt
```

Вызывается автоматически из `deploy.sh` после `extract_data.py` и `process_report.py`.

### Что делает

1. Читает `data.json` (берёт `all_tasks` и `projects`).
2. Отбирает задачи: дедлайн ≤ сегодня **и** статус ∉ `CLOSED_STATUSES` (`Закрыта`, `Закрыто`, `Выполнено`, `Выполнена`, `Завершена`).
3. Группирует по полю `project` (имя проекта, как в задаче) → матч с `projects[]` по имени.
4. Сортировка проектов: max дней просрочки убыв., затем по суммарному кол-ву задач убыв., затем по имени.
5. Сортировка задач внутри проекта: дней просрочки убыв.; задачи разделяются на две подсекции — `⏰ Просроченные задачи (N)` и `📅 Срок сегодня (N)`.
6. Сохраняет `overdue_tasks_DD_MM_YYYY.txt`.

### Формат сообщения

```
📊 Отчёт по просроченным и сегодняшним задачам
Дата: 29.05.2026
Всего: просрочено 1 задача, со сроком сегодня 5 задач в 2 проектах

━━━━━━━━━━━━━━━━

1. 🔵 Имя проекта
👤 Ответственный: Иванов И.И.
🔗 https://transformation.rm.mosreg.ru/#/issues/12345

⏰ Просроченные задачи (1):
   • Тема задачи
     👤 Петров П.П.
     📅 Дедлайн: 15.05.2026 (просрочено на 13 дн.)
     📌 Статус: Новая
     🔗 https://transformation.rm.mosreg.ru/#/issues/13488

📅 Срок сегодня (1):
   • Другая тема
     👤 Сидоров С.С.
     📅 Дедлайн: 29.05.2026 (сегодня)
     📌 Статус: В работе
     🔗 https://transformation.rm.mosreg.ru/#/issues/13500
─────────────────
```

- `🔴` для приоритетных проектов (`is_priority=true`), `🔵` — для остальных.
- Подсекции внутри проекта рендерятся только если соответствующие задачи есть.
- Если задач нет — выводится «✅ Просроченных и сегодняшних задач нет.».

### Ключевые функции

| Функция | Назначение |
|---------|-----------|
| `parse_deadline(s)` | `DD.MM.YYYY` → `date` или `None` |
| `collect_overdue(data, today)` | Группировка задач (дедлайн ≤ today) по проектам с агрегатами `max_overdue` / `total_overdue` / `total_today` / `total` |
| `plural_days(n)` / `plural_tasks(n)` / `plural_projects(n)` | Русская грамматика числительных |
| `_render_task(t, today_task)` | Строки одной задачи; флаг `today_task` управляет надписью даты |
| `build_message(groups, today)` | Сборка текста отчёта (две подсекции: просроченные + срок сегодня) |
